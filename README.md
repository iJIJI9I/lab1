# CrossApp
Наскрізний проєкт з крос-платформного програмування.

## Структура Solution
- `src/Core/` — бібліотека класів (доменна логіка, збір інформації про середовище).
- `src/Cli/` — консольний клієнт (точка входу, форматування виводу).

Предметна область: Склад.
Сутності: Product, StockBatch, Warehouse, Movement.

## Запуск
- Звичайний режим: `dotnet run --project src/Cli`
- JSON режим: `dotnet run --project src/Cli -- --json`

## Режими публікації та порівняння розмірів (win-x64)
| RID | Режим публікації | Розмір publish | Потрібен встановлений .NET Runtime? |
| :--- | :--- | :--- | :--- |
| win-x64 | self-contained | ~77 МБ | Ні (вбудований у пакунок) |
| win-x64 | framework-dependent | ~0.2 МБ | Так (.NET 10) |
